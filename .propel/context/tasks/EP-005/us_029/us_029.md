# User Story - US_029

## Story ID
- ID: US_029

## Story Title
- Calendar Sync (Google & Outlook)

## Description
- As a patient, I want to sync my confirmed appointment to Google Calendar or Outlook Calendar, so that the appointment details appear in my personal calendar with automatic updates on reschedule or cancellation.

## Acceptance Criteria
1. **Given** I have a confirmed appointment, **When** I select calendar sync, **Then** I can choose between Google Calendar and Outlook Calendar.
2. **Given** I choose Google Calendar, **When** OAuth authorization completes, **Then** a calendar event is created via Google Calendar API v3 with provider, date, time, location, and preparation notes.
3. **Given** I choose Outlook Calendar, **When** OAuth authorization completes, **Then** a calendar event is created via Microsoft Graph API v1.0 with full appointment details.
4. **Given** my appointment is rescheduled or cancelled, **When** the status changes, **Then** the calendar event is automatically updated or removed accordingly.
5. **Given** the Calendar API circuit breaker is open, **When** a sync request fails, **Then** the request is queued for async retry and I receive a "Sync pending" notification per NFR-014.

## Edge Cases
- What happens when the OAuth token expires? (System redirects to re-authorization flow; patient must re-authorize per A-6)
- How does the system handle Calendar API rate limits? (Async queue with exponential backoff; patient notified when sync completes)
