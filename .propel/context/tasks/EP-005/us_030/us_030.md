# User Story - US_030

## Story ID
- ID: US_030

## Story Title
- Appointment PDF Confirmation

## Description
- As a patient, I want to receive a professionally formatted PDF document with my full appointment details via email upon booking confirmation, so that I have a printable record of my upcoming visit.

## Acceptance Criteria
1. **Given** my appointment is confirmed, **When** the booking completes, **Then** the system generates a PDF using QuestPDF containing provider name, date, time, location, and preparation instructions per TR-014.
2. **Given** the PDF is generated, **When** the email service is healthy, **Then** the PDF is attached to a confirmation email and delivered via SendGrid to my registered email.
3. **Given** the PDF content, **When** I open the document, **Then** it displays the platform branding, appointment details in a clear layout, and any relevant preparation notes.
4. **Given** I view the patient dashboard, **When** I click "View PDF" on an appointment, **Then** the PDF opens in a drawer overlay for preview per OVL-004.
5. **Given** PDF generation fails, **When** the error is caught, **Then** the system logs the failure and sends a text-only confirmation email as fallback.

## Edge Cases
- What happens when the email service is down during PDF delivery? (PDF is stored; delivery retried with exponential backoff; patient can download from dashboard)
- How does the system handle appointment updates after PDF was sent? (New PDF is generated and sent for rescheduled appointments)
