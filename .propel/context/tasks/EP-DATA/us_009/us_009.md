# User Story - US_009

## Story ID
- ID: US_009

## Story Title
- Clinical Data & AI Entities

## Description
- As a developer, I want EF Core entity models for ClinicalDocument, ExtractedData, PatientView360, DataConflict, MedicalCode, AuditLog, and NoShowRiskScore created with code-first migrations, so that the clinical intelligence and AI domains have a fully operational data layer.

## Acceptance Criteria
1. **Given** the clinical module project exists, **When** I create ClinicalDocument entity, **Then** it includes DocumentID (GUID PK), PatientID (FK), FileName, FileType, EncryptedFilePath, FileSize, UploadedAt, ProcessingStatus (4-value enum), ProcessingError per DR-004.

2. **Given** ExtractedData entity is created, **When** I inspect the model, **Then** it includes ExtractedDataID (GUID PK), DocumentID (FK), PatientID (FK), DataCategory (6-value enum), DataKey, DataValue, Unit, ConfidenceScore (float 0.0-1.0), SourcePageReference per DR-005.

3. **Given** PatientView360 entity is created, **When** I inspect the model, **Then** it includes ViewID (GUID PK), PatientID (FK), JSON columns for Vitals, MedicalHistory, Medications, Allergies, LabResults, Diagnoses, GeneratedAt, LastUpdatedAt per DR-006.

4. **Given** MedicalCode entity is created, **When** I inspect the model, **Then** it includes CodeID (GUID PK), PatientID (FK), CodeType (ICD10/CPT), Code, Description, ConfidenceScore, Status (Suggested/Verified/Rejected), SuggestedBy, VerifiedBy (FK), VerifiedAt, RejectionReason per DR-007.

5. **Given** AuditLog entity is created, **When** I apply the migration, **Then** the AuditLog table is created with append-only constraints (no UPDATE/DELETE permissions granted to application roles).

## Edge Cases
- What happens when JSON column data exceeds SQL Server column size? (JSON columns use NVARCHAR(MAX) with application-level size validation at 1 MB per JSON field)
- How does the system handle float precision for confidence scores? (EF Core maps ConfidenceScore to decimal(3,2) with CHECK constraint between 0.00 and 1.00)
