# User Story - US_040

## Story ID
- ID: US_040

## Story Title
- Medical Code Verification Workflow

## Description
- As a clinical staff member, I want to verify AI-suggested ICD-10 and CPT codes through an accept/reject workflow with tracking metrics, so that the platform maintains >98% AI-Human agreement and ensures clinical accuracy.

## Acceptance Criteria
1. **Given** AI-suggested codes are displayed, **When** I review a code, **Then** I can accept, reject (with mandatory reason), or enter a manual code override per AIR-S04.
2. **Given** I accept or reject a code, **When** the action is recorded, **Then** the MedicalCode status transitions from "Suggested" to "Verified" or "Rejected" with VerifiedBy, VerifiedAt, and optional RejectionReason per DR-007.
3. **Given** verification actions accumulate, **When** the AI-Human agreement rate is calculated, **Then** it is tracked over a rolling 30-day window targeting >98% acceptance without modification per AIR-Q01.
4. **Given** the verification interface, **When** I take an action, **Then** the status updates inline without page reload.
5. **Given** I reject a code and enter a manual override, **When** saved, **Then** the manually entered code is stored as the verified code and the AI suggestion is preserved for model improvement analytics.

## Edge Cases
- What happens when agreement rate drops below 98%? (System logs an alert for admin review; the metric is displayed on the admin dashboard for monitoring)
- What if a staff member tries to verify codes for a patient outside their scope? (RBAC enforcement blocks the action per NFR-009)
