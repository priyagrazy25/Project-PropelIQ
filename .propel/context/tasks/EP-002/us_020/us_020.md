# User Story - US_020

## Story ID
- ID: US_020

## Story Title
- Appointment Cancel & Reschedule

## Description
- As a patient or staff member, I want to cancel or reschedule an existing appointment so that the original slot is released back to the availability pool and waitlisted patients are notified.

## Acceptance Criteria
1. **Given** I have a confirmed appointment, **When** I click "Cancel", **Then** the system updates the appointment status to "Cancelled", releases the slot back to the available pool, and triggers waitlist notifications.

2. **Given** I want to reschedule, **When** I select a new date/time and confirm, **Then** the system creates a new appointment, cancels the old one, and releases the original slot.

3. **Given** a cancellation occurs, **When** the slot is released, **Then** the preferred slot swap queue is checked first, then the waitlist is notified of availability.

4. **Given** a calendar event was synced, **When** I cancel or reschedule, **Then** the calendar event is updated or removed accordingly.

5. **Given** the cancel/reschedule API is idempotent, **When** the same cancellation request is submitted twice, **Then** the system returns the existing cancelled appointment rather than erroring.

## Edge Cases
- What happens when a patient reschedules to a slot that becomes unavailable during confirmation? (409 Conflict returned; patient prompted to select another slot)
- How does the system handle cancellation of a walk-in appointment? (Walk-in appointments can be cancelled by staff only; removed from same-day queue)
