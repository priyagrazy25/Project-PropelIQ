# User Story - US_050

## Story ID
- ID: US_050

## Story Title
- Patient Dashboard

## Description
- As a patient, I want a dashboard that shows my upcoming and past appointments, summary metrics, and quick action links, so that I can manage my healthcare activity from a single hub without navigating manually to each feature.

## Acceptance Criteria
1. **Given** I am logged in as a Patient, **When** I navigate to /dashboard, **Then** I see a persistent app header with logo and notification bell, a left sidebar navigation (Dashboard, Book Appointment, Intake, Documents, Health Profile, Waitlist), a personalized welcome message with my first name, summary cards (upcoming appointments count, intake status, documents uploaded, waitlist entries count), and a "Book Appointment" call-to-action button.

2. **Given** I have booked appointments, **When** I view the Appointments section, **Then** I see a tabbed table with "Upcoming" and "Past" tabs. Upcoming shows appointments with status in [Scheduled, Confirmed, Arrived, InProgress]. Past shows all others (Completed, Cancelled, NoShow, Rescheduled).

3. **Given** I view the appointments table, **When** I look at each row, **Then** I see the provider name, specialty, date & time (formatted), and status badge with color-coded indicators per the SCR-006 wireframe design tokens.

4. **Given** I have upcoming appointments, **When** I click "Reschedule" on an appointment row, **Then** I am navigated to the reschedule page for that appointment.

5. **Given** I have no appointments, **When** I view the Upcoming tab, **Then** I see an empty state with "No upcoming appointments." message and a "Book Your First Appointment" link to /search.

6. **Given** the dashboard loads, **When** the Quick Actions section renders, **Then** I see cards for "Complete Intake" (/intake), "Upload Documents" (/documents), and "Health Profile" (/health-profile) with icons and descriptions matching the SCR-006 wireframe.

7. **Given** the dashboard, **When** any primary feature is accessed via sidebar navigation or quick actions, **Then** it is reachable within a maximum of 3 clicks from the dashboard per UXR-001.

8. **Given** I am on any patient page, **When** I view the sidebar, **Then** the current page's nav item is highlighted with active styling (blue background, left border accent) per SCR-006 wireframe.

## Edge Cases
- What happens when the appointments API fails? (Error state displayed with retry button; waitlist section loads independently)
- What happens when the user has no appointments and no waitlist entries? (Dashboard shows zero counts in summary cards and empty state in table)
